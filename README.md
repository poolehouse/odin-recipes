# Odin Recipes

This project is the **Recipes** assignment from [The Odin Project Foundations course](https://www.theodinproject.com/lessons/foundations-recipes).

## Project Goal

Build a basic multi-page recipe website using only HTML and Git/GitHub workflow practices.

## Assignment Requirements

Based on The Odin Project lesson, this project includes:

- A main `index` page with links to recipe pages
- Multiple recipe pages that contain:
  - A recipe title
  - An image of the finished dish
  - A short description
  - An unordered list of ingredients
  - An ordered list of preparation steps

## Skills Demonstrated

- Writing semantic HTML elements (headings, paragraphs, lists, links, images)
- Structuring a simple multi-page website
- Using Git for meaningful commits
- Publishing and maintaining work in a GitHub repository

## Notes

This project focuses on structure and content. Styling and advanced behavior are added later in the Foundations curriculum.
